# 自主编排细则

> 用户只说「排版这篇 MD」时，Agent **必须**按本节 + `data/wechat-layout-orchestration.json` 自行决策。
> 决策结果在渲染前用简短「编排方案」告知用户。

---

## 1. 先读文章，再选卡

| 信号 | 读什么 |
|------|--------|
| 长度 | 总字数、H2 个数、是否 &gt;5 节 |
| 结构 | table、blockquote、`A/B/C`、 numbered list、阶段词（MVP/V1） |
| 气质 | 第一人称叙事 / 技术文档 / 方法论 / 产品宣言 |
| 金句 | 短加粗句、居中引用、`>` blockquote |

**原则：** 卡片是「章节级强调」，不是段落装饰。一节里只有 1 个核心论点才独立成卡。

---

## 2. 长度 → 模板种类上限

| 档位 | 约字数 | 模板种类 | 典型组合 |
|------|--------|----------|----------|
| 短 | &lt;1500 | 2–3 | T00 + T01 **或** T05 + T08 |
| 中 | 1500–3500 | 3–4 | T00 + T01 + T03/T04/T07 其一 + T08 |
| 长 | &gt;3500 | 4–5 | T00 + 3 种语义卡轮换 + T07/T06 + T08 |

同一模板 **可多用**（两篇 T01 笔记），不算「多模板」。

---

## 3. 文章类型 → 默认方案

### 个人观点 / 种草 / 随笔

- **模板：** T00 → T01（1–2 处）→ T08
- **配色：** `warm` — neutral 正文 + parchment 笔记
- **避免：** T04 除非出现技术段

### 方法 / 框架 / 分层论述

- **模板：** T00 → T02 **或** T01+分条 → T03（若有并列路径）→ T08
- **T02 条件：** 内容有「层级/table/东方 calm」且全篇 **最多 1 张**
- **否则：** 用 T01 笔记 + T07 左线分条替代
- **配色：** `warm-mixed`；有 T03 时用四色对比块默认族

### 产品 / 技术 / 架构

- **模板：** T00 → T04 → T07（若有 roadmap）→ T08
- **配色：** `cool-neutral` — T04 用 charcoal.500；可选 morandi 深替 shell
- **点缀：** sage 标签；高亮用 H2 板岩青（替代 legacy `#64d2ff`）

### 故事 / 案例

- **模板：** T00 → T05 → T01 → T08
- **配色：** `morandi-soft` — T05/T01 surface 用 morandiBlue 50/100，字 **B**

### 路线图 / 计划

- **模板：** T00 → T07 → T08
- **配色：** neutral 壳 + sage tag + parchment 底块

### 元文章 / 清单 / 自检

- **模板：** T00 → T06 → T08
- **配色：** `dark-accent` — 单张 T06 即可，listEmphasis 三色轮换

### 长文 / 深度阅读（少卡片）

- **模板：** L01 + L02
- **配色：** `warm` — L01 中性 + L02 羊皮纸；章内分隔线；圆角 r12

**混合文（常见）：** 取主类型定主色温，按 **semanticTriggers** 插入 1 张异质卡（如观点文里一节 T04 架构）。

## 4. 语义 → 模板（触发器）

| 内容形态 | 模板 |
|----------|------|
| 文首标题+钩子 | T00 |
| 个人经历、痛点、日记感 | T01 |
| 分层 table / 四行层级 | T02（单张）或 T07 |
| 路径 A/B/C/D、并列方案 | T03 |
| Layer、Parser、数据流 | T04 |
| 「然后我发现」案例段 | T05 |
| 卡片清单、本文即测试 | T06 |
| MVP / V1 / 阶段 | T07 |
| 收尾金句、CTA | T08 |
| 日期、版权 | T99 |

---

## 5. 配色组合逻辑

全篇 **Safe 色族 ≤4**。先定 **colorTheme**，再填槽：

| Theme | 主族 | 对比/强调 | 深底 |
|-------|------|-----------|------|
| warm | neutral, parchment | rose, sage | charcoal.300 |
| warm-mixed | neutral, parchment | T03 四块各一族 | charcoal.300 |
| cool-neutral | neutral, morandiBlue | sage | charcoal.500 / morandiDark |
| morandi-soft | morandiBlue 50–100 | parchment | — |
| neutral-warm-accent | neutral | sage, parchment | — |
| dark-accent | charcoal | rose/parchment/sage 轮换 | charcoal.300 |

**规则：**

- 未出现 T03/T06 → 优先 **neutral + parchment** 两族即可
- T03 出现 → 直接用 defaultBindings 四块，不另发明配色
- 莫兰迪底 → 字色 **B/C**，不用 N/W
- T02 不参与全篇 theme，前后用 neutral 过渡
- 深底卡 **全篇 ≤2 张**，且不连续排列

---

## 6. 反模式（禁止）

- 每个 H2 换模板 → 海报化
- 1500 字以内上 5 种模板
- 连续 T04 + T06 深底
- 无并列结构却用 T03
- 全篇 6 色族「展示色板」
- 有 T00 开篇仍把首段再包一张 T01
- 混用 4/6/8/10/18px 圆角（统一 12px）

---

## 7. 决策输出模板

```markdown
**编排方案**
- 类型：{profile} · 约 {字数} 字 · {H2} 节
- 模板：{T00} → {…} → {T08}（共 {n} 种）
- 配色：{theme}；{特殊槽位说明}
- 未使用：{刻意不用的模板及原因}
```

然后直接渲染，无需等待确认（除非用户说「先给方案别生成」）。
